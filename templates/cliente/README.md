# Plantilla de cliente o proyecto

Duplicá esta carpeta como `02_Clients/<slug>/` en tu copia privada. Reemplazá `[Nombre del proyecto]`, completá los campos necesarios y actualizá el índice. Los archivos opcionales pueden quedar en draft o eliminarse ajustando los enlaces.

Arrancá con [el índice](00_index.wiki.md), [perfil](profile.kb.md), [oferta](offer.kb.md), [fuentes](sources/README.md) y [claims](claims-and-risks.kb.md). Sumá el resto a medida que haya evidencia y una tarea que lo necesite.
