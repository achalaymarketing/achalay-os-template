# Inbox

Entrada temporal de material sin destino claro. En una copia privada podés guardar notas de reuniones, ideas o fuentes pendientes de clasificar.

Antes de promover una nota: identificar cliente/proyecto, fecha y origen; extraer hechos relevantes; enlazar las notas de destino y registrar la operación. Si ya conocés el cliente, usá directamente su `sources/`.

Un archivo en Inbox todavía no gobierna decisiones del sistema. Este Inbox se distribuye vacío.
