# Contribuir

Proponé mejoras genéricas para la plantilla: claridad de la guía, enlaces, ejemplos ficticios o herramientas de mantenimiento. Para cambiar contenido, usá una rama y un pull request.

- Mantené español y la gramática del vault.
- Usá únicamente información sintética en ejemplos.
- No adjuntes exportaciones de tu memoria real ni config de proveedores.
- Ejecutá `python3 05_Operations/scripts/check_vault.py`.
- Explicá qué problema resolvés y cómo verificaste el cambio.

Si encontrás datos que parecen privados, evitá repetirlos en un issue público. Contactá al mantenedor por un canal privado ya conocido. Para trabajar con datos propios, partí de una copia privada independiente.
