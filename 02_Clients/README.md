# Clientes y proyectos

Cada cliente o proyecto tiene su propia carpeta, índice, conocimiento, fuentes y campañas. Mantenelos separados al consultar o escribir.

Solo hay un ejemplo precargado: [Taller Demo](demo-taller/00_index.wiki.md), completamente ficticio.

Para crear uno real en tu copia privada, duplicá [templates/cliente](../templates/cliente/README.md), elegí un slug y completá sus placeholders. Seguí el paso a paso de la [guía](../05_Operations/implementacion.wiki.md).
