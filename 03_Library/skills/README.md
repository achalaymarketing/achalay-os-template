# Procedimientos

El [checklist de revisión](../../05_Operations/lint-checklist.skill.md) es un procedimiento `.skill.md`. Para escribir otro, usá [template.skill.md](../../templates/template.skill.md).

Las tres skills cargables viven en [.agents/skills](../../.agents/skills/README.md). Los archivos `.skill.md` planos son documentación; no se instalan automáticamente en el agente.
